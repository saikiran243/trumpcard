Voice off — connect the room first, then enable mic

If the browser blocks the mic or voice can't connect, don't stop playing — start a WhatsApp voice call or FaceTime audio, minimise it, and keep this game open. The talk-starter prompts in the game still give you things to react to together.

How Remote Duel connects now: the two phones meet through a public message relay (over a secure WSS link, with backup relays tried automatically and auto-reconnect if the link drops) — but the relay can never read your game. The 8-letter room code is turned into a one-way hash to name the channel, and every message — names, cards, moves — is encrypted end-to-end in your browser (AES-GCM) with a key made from that code. The relay only ever sees scrambled data on a hashed channel; only the two phones that know the code can unscramble it. The host deals; each screen then shows only that player's own cards, face-down for the opponent. Always read Player 2 the code shown in the green status pill. One browser rule matters: the game must be open as its own page in Safari/Chrome (not embedded inside another app or preview) for secure connections and encryption to work. If a room still can't be made, fall back to Pass & Play on a shared FaceTime screen.

🌍 US ↔ INDIA — PLAY & TALK ON DIFFERENT DEVICES

This game was made to give you both something to talk about, not just cards to tap. The cards hand you the next line — a stat to argue about, a legend to pick sides on. Pick one way to talk and stick with it for the whole match:

🎤 Best: Voice inside this game
Join the same Remote Duel room, then both tap Enable Mic & Talk. One link, cards + voice together. No WhatsApp juggling. Earphones recommended.
📞 Just as good: WhatsApp / FaceTime alongside
Start a WhatsApp voice call (lighter than video) or FaceTime audio, minimise it, then open this game and join the room. Voice keeps playing in the background while you play.

✅ Before you deal — 2-minute check on both phones

1Same link, two devices
Send this page's link to Player 2. Each person opens it on their own phone/tablet — one device per player. Don't share one screen for Remote Duel.
2Same room code
Host taps Create Room and reads the room code out loud. Guest picks Player 2 — Guest, types the same code, taps Join Room. Wait for the green “Connected” pill.
3Allow the microphone
When the browser asks, tap Allow for mic. If you tapped Block by mistake: tap the 🔒 / site settings in the browser address bar → Microphone → Allow, then reload. Safari (iPhone) and Chrome (Android) both work.
4Sound check
Say “Can you hear me?” after both mics are on. If there's echo, plug in earphones. If voice still fails, switch to a WhatsApp voice call and keep playing — the game syncs separately.
5Keep this tab open
Don't close the game tab during the match. Locking the phone or switching apps for a long time can drop the link — if it drops, re-join with the same code and the Host re-deals.
6Final 3 rule — still private
Down to your last 3 cards? You'll see all 3 and choose one to play. The other player never sees your 3 — only the card you actually play.

Proper duel steps:

  1. Both open this page and pick Remote Duel above.
  2. Player 1 (Host) taps Create Room and reads out the room code. Player 2 selects “Player 2 — Guest”, types that code and taps Join Room.
  3. Both tap Enable Mic & Talk and do the sound check — or start your WhatsApp / FaceTime call now.
  4. Host taps Toss the Coin & Deal. From then on your cards are only on your screen and their cards are only on theirs — the opponent's pile stays face-down.
  5. On your turn you tap one stat on your card. That single stat is what's compared, the round resolves on both screens, and play moves on. The winner calls the next stat. Use the 💬 Talk Starter card in the game whenever it goes quiet — tap Next prompt for a new one; it changes on both screens together.

Quick way (one shared screen): on FaceTime tap Share → Share My Screen, open Pass & Play here, and the other player just calls their stat out loud (“Runs!”) while the host taps it.

Sharing the game: send the other player this page's link — it opens in any phone browser with no install, in the US and in India. A Roblox version would be a separate rebuild inside Roblox Studio (Roblox can't run a web page), so the Remote Duel above is the fastest way to play each other.
